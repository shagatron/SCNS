# Connections-v1 draft contract

`patch.schema.json` is generated from the authoritative Pydantic API union: `make generate-api`. Send `{ "changes": [{ "entity": "connectors", "id": "<stable UUID>", "data": { ... } }] }` to the selected campus/draft connections preview or PATCH endpoint. A missing `data` means explicit deletion. Each entity/UUID occurs once per batch; maximum500 changes. UUIDs stay stable across clones and retries; identity is never inferred from a label. Existing IDs update; absent IDs insert; unknown referenced IDs reject the whole transaction. Requests require live campus edit permission, Origin, CSRF and current quoted draft-wide `If-Match`. A retry with an old version conflicts, rather than duplicating a write.

The admin forms expose all fields. Survey CSVs in this folder are collection worksheets, **not automatic staged-import mappings**: enter verified values through the connector UI/typed API after surveying and selecting the current plan. Staged CSV/JSON/GeoJSON import retains its existing outdoor catalog scope. No new bulk connector import or publication shortcut is provided.

- `policies`: ID equals floor UUID; explicit current floor/layer UUID, enabled false/true, mode metric/directions_only. Enabling requires dated topology evidence and independently approved selected source; metric requires approved calibration. Missing/disabled policy means display-only.
- `connectors`: building UUID, unique building code, label, stairs/lift/ramp/entrance, static available/unavailable/unknown, visibility, private evidence/date.
- `stops`: connector UUID, floor/current selected layer UUID, stored indoor node UUID in that same building/floor/frame. Entrance group stops must use entrance-kind nodes.
- `paths`: connector, physical-pair UUID, explicit from/to stop UUIDs on distinct floors. One directed row is one-way; a reverse pair must agree on shared costs/access/availability/evidence. No fabricated pixel/geographic line joins floor frames.
- `transitions`: entrance connector, stop, explicitly mapped outdoor building anchor UUID, direction in/out, physical-pair UUID, priority (lower breaks equal-cost ties). Geographic outdoor anchor and local indoor stop remain separate.

Distances: full traversal metres `distance_m` is NULL iff status unknown; known status is measured or estimated. Estimated new transition/connector distance is excluded from metric-shortest; original stored geodesic outdoor estimated edges remain compatible. Horizontal distance and vertical rise magnitude are nullable measured components, never floor ordering-derived height. Time: positive baseline traversal seconds and nullable nonnegative baseline wait. Lift ETA needs both; static estimates do not model occupancy. Width/slope/step count/surface are nullable. Do not use empty0 as unknown. Accessibility defaults unknown; verified_step_free requires dated evidence and no positive steps; stairs never qualify. Private evidence/date/verifier are excluded from public projection. `uncertainty_note` is public-facing explanatory text; do not put confidential notes in it.
