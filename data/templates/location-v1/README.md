# Transient outdoor observation schema

`observation.schema.json` is generated by `make generate-api`. These are request contracts, not database/import templates or instructions to save user positions. Source/routing/match contracts appear in generated OpenAPI/TypeScript. Preserve no raw GPS samples or movement traces in repository, uploads, browser storage, logs or analytics.

Synthetic Gate fixture only: latitude0.0002, longitude0.00015, accuracy_m5, observed_at=current UTC ISO timestamp. Send only after user action to the current campus/release/overlay matcher, then physically confirm the suggested landmark in the synthetic test workflow. Revalidate on each route. Real GPS on this invented campus should normally fail coverage; do not shift campus data or persist coordinates to make it pass.
