## Visual direction

Keep the existing editorial page, full directory and original planner. Warm cream/amber/ink replace acid yellow/light gray accents; borders are consistent. Only the non-demo campus with metadata `code=MUJ` receives the owner-supplied campus photograph and emblem. Loading/Demo/other/name-only matches do not request university images. Existing SCNS title, named campus, selector/QR locking, links/status/section targets and all surrounding content remain. A concise student-project/not-official-service attribution is visible with the emblem.

The backdrop uses the actual ZIP photograph, with desktop/small/portrait WebP derivatives and no upsampled pixels. Desktop retains building composition; mobile uses a symmetric source crop with the complete dome/finial, and caps/fades the **painted background** rather than clipping content when a long name increases hero height. A restrained dark gradient supports foreground contrast. The original transparent emblem is unaltered, naturally proportioned, and rests on a plain cream backing above the photograph. No glass/neon/decorative animation, watermark logo or substituted imagery.

Absolute photo placement, eager/high-priority loading and allocated logo dimensions prevent image loading/failure from moving controls. The photo is decorative/hidden from assistive tech; logo has meaningful alt text. Solid dark photo fallback retains text/controls; fixed-size explicit emblem-unavailable text retains layout. Existing links/selector perform normal navigation and campus changes; no image-specific API, permission, polling or app mode is added. Reload/campus switch retries a failed asset.
