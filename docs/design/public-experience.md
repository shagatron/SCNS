# SCNS public experience: editorial design

Based on the four supplied reference images inspected13October2026: right-heavy oversized hero with a narrow yellow information panel/faint lettering; ruled large numbers; asymmetric numbered process rows/rectangular accent illustration; strong letter-based destination tiles. The composition is adapted to original SCNS copy and working public APIs. No forge identity, business statistics, portfolio names, campus photographs or stock marketing claims are copied.

Near-black framing/text, off-white sections and acid-yellow #E4FB02 form the public palette. Thin rules and generous whitespace separate sections; only the outer surface, floating pill navigation and circular arrow receive deliberate rounding. The selected route uses a high-contrast black stroke, with labelled yellow start/white destination markers where the endpoint belongs to the displayed geographic/floor frame. A labelled graph illustration explains connections without pretending to be a navigable map.

Inter variable is self-hosted under frontend/public/fonts, with the upstream SIL Open Font License included. Font-display swap and Arial/system fallbacks preserve readability; no third-party font request, tracking, new dependency or changed lockfile. The352,240byte font is a separate cacheable asset, not a claim of later4F performance targets. Source: https://github.com/rsms/inter/tree/master/docs/font-files (InterVariable.woff2), upstream LICENSE.txt retained as OFL.txt.

The App shell contains campus selection, intro and public state handling; CampusExplorer retains existing release/closure/GPS/QR/routing state; PublicExperience supplies navigation, safe reveals and published overview/process content. Existing search/directory appears once and uses real published records. Totals are search.total, complete map footprints inside selected campus extent (omitted when truncated/unavailable), and approved public floors. No arbitrary building/place count or private draft record is substituted.

Mobile navigation groups intro/overview/how under Home while keeping Places and Explore distinct; desktop highlights each section individually. Readiness failure is labelled unavailable rather than left as checking. The explorer has a stable /#explorer entry and preserved #planner/query links. Map dimensions increase; route controls are a native keyboard-accessible details element, open by default, with results outside it so collapsing controls never hides directions. Directory start/destination actions expand controls before focusing the field. Outdoor/floor selection, nullable metrics, transitions, no-route/refresh/restriction disclosures and all location confirmation/expiry/privacy behavior are retained. QR confirmation notice is beside the explorer; public QR resolution/errors/loading use the same scoped language. No report placeholder/4D functionality.

Native smooth scrolling and a passive scroll/resize listener update the floating navigation; requestAnimationFrame is scheduled only in response to events. IntersectionObserver adds short once-only reveals, with content visible by default; missing initialization never hides it. Reduced motion disables public animations/transitions/smooth scrolling. No scroll snapping, wheel interception, continuous animation, sticky illustration or animation dependency. The map column is sticky on wide screens and static on mobile; one100px header offset avoids double spacing and obscured focus. Deferred direct/keyboard targets wait for real explorer/planner content.

All public tokens/selectors sit under .public-app (only root scroll behavior conditionally uses :has(.public-app)). Admin code/global/admin CSS is untouched. Backend/API/schema/algorithms/permissions/audits/publication/private-original/closure contracts are unchanged. Only test harness coverage changes outside the frontend. Official university mapping, real accessibility, positioning and field verification remain unavailable.

Frontend packaging explicitly grants read/traverse permission to its public build tree: a restrictive checkout umask otherwise copied fonts/SVGs as root-only files, causing nginx403/font load errors. Private source/storage/env files are excluded from build context; no private volume permissions are modified. Built tests assert the actual WOFF2 binary and loaded font face.
