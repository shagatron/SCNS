4A and4B are delivered. This branch implements **only4B**. 4C–4F remain planned, not delivered. 4B uses explicit operator-confirmed reopening; an estimated end never automatically reopens a lift. Scheduled restrictions are conservatively excluded across a declared route window, with unknown ETA handled safely. Embedded camera scanning is optional; native camera opening a link is sufficient. Local HTTP loopback is a Docker demo exception; nonlocal canonical signage requires a configured HTTPS origin before a separately authorized deployment. No M5/real MUJ import/public deployment is part of this change.
