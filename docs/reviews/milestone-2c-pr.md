## Milestone 2C: exact-content draft review, publication and rollback

Draft/catalog/import/graph changes remain private until an independent campus reviewer approves the exact validated content and confirms publication. The complete workflow combines authoritative whole-draft diagnostics and computed standard/step-free expected routes, warning acknowledgements, source rights/provenance and privately stored originals, reviewed public vector derivatives, submit/reject/withdraw/approve states, contributor separation, and stale-evidence invalidation.

Publication generates a reproducible immutable public artifact, freezes the approved revision, records publisher/decision/checksums/action/audit and changes the active pointer in one transaction. Failed generation/audit/writes retain the previous release and consistent draft state; same-payload retries return prior results. Rollback explicitly selects an earlier immutable publication against the expected pointer, preserves history and audits the reason. Monotonic publication order handles drafts published out of creation order. Public search/map/directory/routing share one frozen revision; release-pinned clients clear stale routes and recover coherently, including failed metadata refresh.

Responsive admin source/derivative review, diff/diagnostics/evidence, decisions and confirmed publish/rollback/history screens reuse campus sessions, CSRF, optimistic concurrency and audit. Restricted records, original properties/geometry, private notes/evidence, identities and raw files never enter the public artifact. Earlier approved artifacts remain immutable. Existing Demo Campus name/release and admin/import/graph/navigation workflows are preserved.
